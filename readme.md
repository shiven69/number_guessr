Number Guessing Game 🎲

A simple, short, and fun command-line game built in Python. This is a perfect first project for beginners to understand loops, conditionals, and user input!

🚀 What it does

The computer randomly selects a secret number between 1 and 10. Your goal is to guess the number. After each guess, the computer will tell you if your guess was too high, too low, or exactly right.

🛠️ Requirements

Python 3.x installed on your computer.

No external libraries needed (it uses Python's built-in random module).

🎮 How to Play

Save the code: Create a new file named guessing_game.py and paste the game code inside.

Open your terminal: Open your command prompt (Windows) or terminal (Mac/Linux) and navigate to the folder where you saved the file.

Run the game: Type the following command and press Enter:

python guessing_game.py


Start guessing! Follow the on-screen prompts to play the game.

🧠 Concepts Learned

This 15-line script covers core Computer Science concepts:

Variables: Storing data (like the secret number).

while loops: Repeating the prompt until the correct answer is guessed.

if/elif/else conditionals: Making decisions based on whether the guess is too high or too low.

Type casting: Using int() to convert text input into a mathematical number.
