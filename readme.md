# Number Guessing Game 🎲

The **Number Guessing Game** is a simple and fun Python project for beginners. In this game, the computer randomly chooses a number between **1 and 10**, and your job is to guess what it is.

After every guess, the program gives you a hint. It tells you whether your number is **too high**, **too low**, or **correct**. Keep guessing until you find the right number!

## 🚀 How It Works

- The computer randomly selects a number from **1 to 10**.
- You enter your guess.
- The program checks your guess against the secret number.
- If your guess is too high or too low, you get a hint.
- The game continues until you guess the correct number.

## 🛠️ Requirements

You only need:

- **Python 3.x**
- A computer with Command Prompt or Terminal

No extra libraries are required because Python's built-in `random` module is used.

## 🎮 How to Play

1. Create a new Python file called `guessing_game.py`.
2. Copy the game code into the file.
3. Open **Command Prompt** or **Terminal**.
4. Go to the folder where you saved the file.
5. Run the program using:

```bash
python guessing_game.py
```

6. Enter your guesses and try to find the secret number!

## 🧠 What You Learn

Although the game is small, it helps you practice some important Python basics:

- **Variables** – used to store the secret number and your guess.
- **`while` loop** – keeps the game running until you guess correctly.
- **`if`, `elif`, and `else`** – check whether your guess is high, low, or correct.
- **User input** – allows the player to enter a number.
- **Type casting** – `int()` converts the input from text into a number.
- **`random` module** – generates the computer's secret number.

It's a small project, but it's a great way to get comfortable with the basics of Python while building something you can actually play! 🎮
